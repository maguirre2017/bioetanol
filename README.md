## Publicación en GitHub Pages

1. Subir **el contenido de esta carpeta** a la raíz del repositorio.
2. En GitHub: `Settings > Pages`.
3. En `Build and deployment`, seleccionar `Deploy from a branch`.
4. Elegir la rama `main` y la carpeta `/ (root)`.
5. Guardar.

No requiere compilación, Node.js ni dependencias externas.
